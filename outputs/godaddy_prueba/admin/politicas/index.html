Aplicación de control operativo y checadas

Política de Privacidad

Última actualización: 28 de junio de 2026

Responsable del tratamiento: Promosoluciones en Fulfillment.

Esta política informa cómo se recaban, usan, almacenan y protegen los datos personales tratados por la aplicación móvil y el panel web operativo de Promosoluciones.

1. Alcance

Esta política aplica a las personas usuarias autorizadas para operar la aplicación móvil de checadas y el panel web administrativo, incluyendo promotores, supervisores, administradores y personal autorizado por Promosoluciones en Fulfillment.

La aplicación no está dirigida al público general. Su uso está limitado a personal autorizado para registrar asistencia, validar presencia en tienda y consultar información operativa relacionada con sus funciones.

2. Datos personales que podemos tratar

Para operar correctamente el sistema, podemos tratar las siguientes categorías de datos:

  • Datos de identificación laboral: nombre, RFC, número de empleado, correo electrónico, teléfono, rol, estado del usuario, supervisor asignado y permisos operativos.
  • Datos de autenticación: usuario, contraseña cifrada o protegida, sesiones y tokens de acceso.
  • Datos de checada: fecha, hora, tipo de registro, tienda, cadena, supervisor, estatus del registro, notas operativas y resultado de validación.
  • Ubicación precisa: latitud, longitud, distancia contra la tienda más cercana, precisión del GPS e indicadores técnicos usados para validar que la persona se encuentra dentro del radio autorizado.
  • Fotografía de evidencia: imagen capturada durante la checada para verificar identidad y presencia en tienda.
  • Datos técnicos del dispositivo: identificador del dispositivo, sistema operativo, estado de sincronización, registros técnicos de errores, dirección IP y datos necesarios para seguridad y auditoría.
  • Avisos internos: visualización de comunicados operativos, mensajes o imágenes publicados para el personal autorizado.

3. Finalidades del tratamiento

Los datos se utilizan para las siguientes finalidades:

  • Registrar entradas, salidas, comidas y verificaciones de ubicación.
  • Validar que las checadas se realicen dentro del radio autorizado de una tienda.
  • Prevenir registros duplicados, falsificación de ubicación, manipulación de hora o uso no autorizado del sistema.
  • Generar reportes, tableros, consultas de asistencia y seguimiento operativo para supervisores y administradores.
  • Permitir la operación sin conexión temporal y sincronizar los registros cuando el dispositivo recupere conexión a internet.
  • Administrar usuarios, roles, tiendas, cadenas, permisos, avisos internos y accesos.
  • Dar soporte técnico, mantener la seguridad del sistema y atender revisiones o auditorías internas.

4. Uso de cámara y ubicación

Cámara

La cámara se utiliza únicamente cuando la persona usuaria inicia una checada y captura una fotografía de evidencia. La aplicación solicita la cámara frontal para generar una selfie asociada al registro.

Ubicación

La ubicación se utiliza para determinar si la persona se encuentra dentro del radio autorizado de una tienda. La aplicación no está diseñada para dar seguimiento continuo en segundo plano; la ubicación se obtiene para validar el registro cuando se realiza una checada o una verificación solicitada.

5. Base de uso y acceso interno

El tratamiento de los datos se realiza para cumplir finalidades laborales, administrativas, operativas y de seguridad vinculadas con la prestación de servicios de Promosoluciones en Fulfillment y la supervisión de actividades en tienda.

El acceso a la información está limitado por roles. Los promotores pueden consultar sus propios registros; los supervisores pueden consultar información de personal asignado; los administradores pueden consultar y administrar la operación completa conforme a sus permisos.

6. Transferencias y encargados

Promosoluciones en Fulfillment no vende datos personales. La información puede compartirse únicamente con:

  • Personal interno autorizado que requiera la información para supervisión, administración o soporte.
  • Clientes o responsables operativos autorizados, cuando sea necesario para validar cumplimiento de servicios.
  • Proveedores tecnológicos que prestan servicios de alojamiento, infraestructura, seguridad, soporte o mantenimiento.
  • Autoridades competentes, cuando exista una obligación legal o requerimiento formal.

7. Conservación de la información

Los datos se conservan durante el tiempo necesario para cumplir las finalidades operativas, laborales, administrativas, fiscales, legales y de auditoría aplicables. Las fotografías y registros de checada se conservan como evidencia operativa mientras sean necesarios para consultas, reportes, aclaraciones o cumplimiento de obligaciones.

Cuando la información deje de ser necesaria, se eliminará, bloqueará o anonimizará conforme a los procedimientos internos y obligaciones legales aplicables.

8. Seguridad

Se aplican medidas técnicas y administrativas para proteger la información, incluyendo uso de conexión segura HTTPS, control de acceso por usuario y contraseña, manejo de roles, contraseñas protegidas, restricciones para consultar fotografías y controles de sesión.

Ningún sistema es completamente inmune a riesgos. Por ello, las personas usuarias deben mantener la confidencialidad de sus credenciales y reportar cualquier acceso no autorizado o comportamiento inusual.

9. Derechos de las personas usuarias

Las personas usuarias pueden solicitar acceso, rectificación, cancelación u oposición respecto de sus datos personales, así como consultar dudas sobre el tratamiento de su información, de acuerdo con la legislación aplicable en materia de protección de datos personales.

Algunas solicitudes pueden estar sujetas a validación de identidad, conservación obligatoria por razones legales, laborales o administrativas, o a restricciones cuando la información forme parte de evidencia operativa necesaria.

10. Datos almacenados temporalmente sin conexión

Cuando no exista conexión a internet, la aplicación puede guardar temporalmente en el dispositivo datos de la checada, ubicación y fotografía para sincronizarlos posteriormente. Esta función se utiliza para permitir continuidad operativa y no sustituye las validaciones de seguridad del sistema.

11. Cambios a esta política

Promosoluciones en Fulfillment puede actualizar esta política para reflejar cambios legales, técnicos u operativos. La versión vigente estará disponible en esta misma dirección electrónica.
